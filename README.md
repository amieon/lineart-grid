# 线稿临摹网格工具

练型准用的小工具：把参考图变成**黑白线稿**，叠上 **n×n 网格**照着画；画完用手机拍下来，提墨成白底透明，**和原图叠在一起或做差值**，一眼看出哪根线画偏了。

全程本地跑图像处理，只有调模型的那两个按钮花钱。打包出来是一个免安装的 exe，双击就能用。

---

## 用法

### 1. 直接用 exe

拿 `release/lineart-grid.exe`，双击即可（不需要装 Node）。它会在 exe 同级目录读写两样东西：

| 文件 / 目录 | 作用 |
| --- | --- |
| `.env` | 存 API Key 和模型名。没有也能启动，只是用不了 AI 出图 |
| `linearts/` | 线稿库，存每次花钱出的原稿（`<id>.png` + `index.json`） |

`.env` 手动编辑也行，也可以直接点界面右上角的徽章，在弹窗里填 Key —— 保存就是写这个文件，不会上传到任何地方。窗口里嵌的是同一个本地服务，先试 5173，被占用就换一个随机端口，所以同时开两个实例也没问题。

### 2. 从源码跑

```bash
npm install
npm start                 # http://localhost:5173
```

Key 有两种放法，任选其一：复制 `.env.example` 为 `.env` 填好（Windows 上 `copy .env.example .env`），或者直接点界面右上角的徽章填 —— 保存时服务端会自动创建/更新 `.env`。端口被占用会明确报错（`端口 5173 已被占用`），改 `.env` 里的 `PORT` 或关掉另一个实例。

### 3. 手机上同 Wi-Fi 看

`npm start` 启动后终端会打印局域网地址，手机浏览器打开同一个页面就能看图、存图。出于安全，**改 Key 的接口只接受本机请求**，手机上动不了设置。

## 界面：顶上三个功能页

侧栏只显示当前这一页要用的分组，切页不会重复付费。

### 转线稿

1. **图片** — 拖进去或点选，长边建议 ≤ 2048px。
2. **生成线稿** `AI · 按张计费` — 调 qwen-image-edit 把图转成白底黑线，提示词可改。结果自动存进线稿库。
3. **本地抽线** `免费` — 不调模型，在浏览器里把图提成线稿。两种方法：
   - **自适应阈值提墨（Sauvola）** — 手绘稿、纸扫描首选。用积分图 O(1) 取窗口局部 mean/std，阈值 `t = mean·(1 + k·(std/R − 1))`，比局部背景「明显更黑」的算墨；再可选 Zhang-Suen 骨架化把实心笔画收成居中线（治「一条软笔裂成两条描边」）。
   - **边缘检测（Canny）** — 照片、明暗渐变。双边滤波保边 → Scharr 梯度 → 非极大值抑制 → Otsu 自动定双阈值 → 滞后连通 → 连通块尺寸过滤 → 膨胀加粗。
   - 长边先压到 1600px（双边滤波是 O(n·k²)，大图会卡）。
4. **图像处理** `免费 · 可反复` — 点「应用处理」才跑，顺序固定为：空间卷积核（高斯 / 均值 / 锐化 / 拉普拉斯 / Sobel，在源尺寸的灰度上）→ 中值去噪 → 自动裁白边 → 2× 放大 → 色阶二值化（软过渡带 ±45）→ 形态学。去噪必须在裁边前面，否则靠边的杂点会把包围盒撑大、裁不掉。形态学的「次数」= 结构元半径（核是 3×3，一次啃 1px），所以填宽 d px 的白洞要 ⌈d/2⌉ 次。
5. **网格 / 导出** — 格数 2~20，格号、线色、粗细、透明度、强制正方形格；导出线稿 / 带网格 / 原图带网格 / 纯空白网格（透明背景，垫纸下用）。

### 叠加对比

把临摹照片和参考线稿对在一起：

- **提墨方式**三选一：`本地`（吃「本地抽线」那组的参数，免费可反复）／`AI`（花钱，见下）／`不提墨`。
- 白变透明不用阈值化（会把淡笔弄断、还留白边），而是 `alpha = 255 − 灰度`，浓淡保住。
- **三种叠法**：半透明叠（看整体偏移）／**差值**（重合=黑，偏一点就发亮，最客观）／闪烁切换（按住空格只看原图）。
- 两层各自可平移、缩放、旋转：按住图拖动 = 挪选中的那一层，**Ctrl+滚轮** = 缩放这一层（加 Shift 精调）。
- 手机拍摄的远近和角度不可能和原图一致，所以有**「自动匹配大小」**：按两层**墨迹包围盒**（不是画布尺寸）把选中层缩放对齐。照片带角度时包围盒会偏大（实测约 3.4%），先把旋转调正、再点一次更准。
- 「导出对比图」连网格一起存 PNG。

### 线稿库

每次 AI 出的原稿都自动存在这里，随时点开载入、本地反复处理，**不会重复花钱**。库里标「照片」的是 AI 提墨结果，载入时回到照片层而不是盖掉参考原图。

## 花钱这件事

DashScope 图像模型按**成功生成的图片张数**计费，和分辨率无关（本工具固定一次一张），所以请求 2048 出图并不多花钱。

界面上只有两个入口会调模型，都必须**显式点按钮**：「生成线稿」和「AI 提墨（花钱 · 一张一次）」。切页、切下拉框、拖动、导出、改参数全都不花钱。任何花钱的产物都会自动进线稿库，并且单独留一份在内存里，切去本地再切回来也不会重复付费。

**AI 提墨的取舍**：模型天生想把画「修好看」——把你抖的线画直、断口接上，而对比要的恰恰是忠实原样。提示词里已经写死「不许修正、不许美化、不许补线」，但要最忠实仍然建议用本地提墨，只有光照阴影乱到本地提不干净时才上 AI。（同样的原因，本地抽线在手绘稿上其实比边缘检测更「对」：边缘检测会把一条有浓淡的软线找出两个边。）

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/config` | 当前模型、Key 是否已配置、`.env` 路径 |
| POST | `/api/config` | 写 Key / 模型到 `.env`，**只允许 127.0.0.1** |
| POST | `/api/lineart` | 调模型出线稿，成功后自动入库 |
| GET | `/api/gallery` | 线稿库列表 |
| POST | `/api/gallery` | 手动把当前线稿存入 |
| GET / DELETE | `/api/gallery/:id` | 取图 / 删除，id 走 `[a-zA-Z0-9_-]+` 白名单防目录穿越 |

图片走 base64 data URL 而不是模型返回的 URL：那个链接 24 小时过期，而且跨域会污染 canvas 导致导不出来。

## 结构

```
server.js            零依赖的本地服务：静态文件 + 三个接口 + 线稿库存盘
public/app.js        所有前端逻辑：模型调用、本地抽线、处理管线、叠加对比
public/index.html    三个功能页的控件（分组用 data-tab 声明自己上哪一页）
electron/main.cjs    窗口 + 决定 .env 和 linearts/ 落在哪
```

图像处理全在浏览器里跑，服务端只做模型转发和存盘，除了 Electron 本身没有别的运行时依赖。

## 打包

```bash
npm run app    # 不开浏览器，直接在 Electron 窗口里跑（开发时用）
npm run dist   # 打成 release/lineart-grid.exe
```

改了 `public/` 里任何东西都要重新 `npm run dist` 才会进 exe。构建配置在 `package.json` 的 `build` 字段：`.env` 和 `linearts/` 都不进安装包，Key 只留在本机。

## 已知毛病

- 便携 exe 每次启动会重解压到临时目录，所以线稿库和 `.env` 都放在 exe 真实所在目录，别把 exe 单独拷到只读位置。
- 照片没做透视校正（纸面拍歪只能靠旋转近似），纸面轻微倾斜由 Sauvola 的局部窗口容忍。
- 旋转过的墨迹包围盒必然大于真实范围，「自动匹配大小」第一次会略偏小，调正旋转再点一次。
